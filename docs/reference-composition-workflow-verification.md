## Automated-review regressions

A failed replacement/second-profile import now retains the prior applicable composition result while the request is pending (Apply remains disabled during work), then restores Apply availability on failure with the original diagnostic. An already-invalid crop has no retained result and cannot become applicable through a failed import. The regression failed on both profile paths before the fix. Native QA loaded a flattened existing Front image, imported an invalid Side PNG, observed the decode diagnostic alongside the retained composed preview and enabled Apply, scrolled to the origin control while the footer remained fixed, then recovered through the app command to the clean document.

Flattened-image reuse now reads a guarded `referenceImageForComposition`: it is unavailable during decode, after a decode error or without a document asset. The action is disabled while unavailable and rechecks current readiness when clicked. A controlled actor retains the old cached raster while replacement bytes are already committed, proves the guarded value is nil during the suspended replacement decode, then releases the current raster and verifies reuse becomes available. This suspended interval has automated coverage; no native timing claim is made for it.

The separate file-picker failure callback now reports its diagnostic without invalidating an intact composition. A regression verifies valid preview/Apply preservation, continued rejection of invalid crop drafts and ignored errors after Stop. This callback is distinct from selected-file decoding; provider failure timing is not claimed as native-tested.

Rejected picker input and rejected pointer rectangles now share a non-invalidating diagnostic path; invalid numeric crop drafts still invalidate Apply. A regression uses a greater-than-three-point drag on a magnified 4×2 source whose endpoints round to the same pixel boundary, confirms projection rejection, and verifies that the original crop/PNG survive and Apply resumes after the active gesture ends.
