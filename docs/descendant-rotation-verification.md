# Descendant rotation verification

Full `make ci` passes 256 XCTest tests, formatting, native builds, coverage and Qt-free linkage for both apps. Swift line coverage: mesh 66/67; document 1904/1981; editor model 1038/1044; pure editor state 453/453; undo 97/97. DescendantRotation measures 42/42 lines and 24/24 regions. These numbers do not measure inherited C++ coverage.

TDD first failed on the absent rotation model/session APIs; the controller test then failed on its missing wrapper. Six model/session tests cover all four directions, a fixed pivot and parent side, unrelated nodes, radii, selection, unknown XML and opaque assets, exact undo/redo and save/reopen. They distinguish 3D parent distance from projected distance, deterministic ties, cycles, endpoints and isolated nodes; test Front/Side axis locks and read-only traversal; and reject invalid selection, unavailable origin, read-only pivot and out-of-bounds proposals atomically. Locked/isolated no-ops preserve redo. Separate sessions remain independent.

Pinned-core compatibility exercises all four actions on the valid Capsule fixture and produces nonempty geometry, retaining three nodes and one part and exact undo. Synthetic cycle/cross-part cases are pure command tests, not engine topology-support claims. The controller test verifies availability, preview regeneration, stable camera reset count, exact undo and atomic multiselection rejection.

Native QA reused the existing QA app path and bundle identity with a disposable Capsule copy. With no selection, all four Canvas actions were disabled. Selecting Node 2 enabled inspector and Canvas actions. Front clockwise kept the pivot at (0.5, 0.5, 1), moved Node 3 to (0.25, 0.5, 1), and retained Node 1 at (0.5, 0.25, 1). The rendered 80-triangle mesh updated; saved XML independently confirmed the coordinates. After Undo, Side clockwise from Canvas moved Node 3 to (0.5, 0.5, 0.75). Undo restored its original position. With X/Y locked, Front clockwise left Undo disabled and Redo available. After unlocking and saving the restored state, the complete archive compared byte-identical to Capsule.ds3. Rendered Front geometry and native controls were inspected; no unavailable design baseline was invented.

Qt source comparison covers its nearest-origin neighbor and connected traversal algorithm. Native locks intentionally differ from Qt's temporary lock disabling, as documented in [ADR 0026](adr/0026-descendant-rotation.md). Full Qt GUI round trips, rotated-profile differential checks and broader accessibility/performance acceptance remain pending. Physical origin dragging remains separately tracked in #45.
