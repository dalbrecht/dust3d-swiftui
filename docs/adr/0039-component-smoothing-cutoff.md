# ADR 0039: Component normal smoothing cutoff

Status: Accepted. Tracks #62.

Expose the inherited component `smoothCutoffDegrees` property with its Qt inspector
range of 0–180 degrees. Zero keeps sharp edges; the core merges neighboring face
normals only within the cutoff. It does not change geometry. Component-level
smoothing applies to the geometry generated by that component; it does not invent
inheritance rules for descendant component settings.

Missing/empty source values read as zero. Nonfinite, out-of-range or malformed
source values remain unavailable metadata and stay preserved on unrelated edits.
Explicit valid replacement is allowed. The typed command rejects invalid numbers
atomically and removes the source attribute for an actual change to zero, matching
upstream serialization. Semantic no-ops retain source spellings and redo.

Use text-based per-inspector drafts with explicit Apply/Reset and Return-to-apply.
No native numeric formatter retains an independent unparsed buffer. Reset discards
only unapplied text; applying zero is an explicit undoable reset of the property.
Selection changes and published cutoff changes refresh the draft. Unsupported
source metadata gets an explanatory label and an empty replacement field.

Apply uses the existing actor/history/preview path. Regenerate normals without
resetting camera or selection. Editing-axis/radius locks remain node-transform
constraints, as in the inherited component setter. Invalid input surfaces a typed
range diagnostic without publishing an edit or starting generation.

Verify actual pinned-core normals: smoothing changes normals while positions and
triangle counts remain fixed; normals remain finite and normalized. Test source
preservation, bounds, exact history, no-ops and atomic invalid batches. Native
Apply/Reset/save/history checks and Qt differential modifier acceptance are separate
from headless tests. No new dependency, core pin or C++ change is required.
