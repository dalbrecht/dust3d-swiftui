# ADR 0024: Transaction-scoped empty-part cleanup

Accepted 2026-10-16. Tracks #49; completes graph-owner cleanup after native session deletion.

Keep low-level `.removeNode`/`.removeNodes` commands focused on nodes and incident edges. Add explicit `.pruneEmptyParts(ids)` to remove only validated empty editable owners. Duplicate, missing, nonempty or readonly targets reject atomically; an empty target list preserves original bytes. Assets are never garbage-collected.

The session's existing deletion preflight tracks affected part identities across the entire command batch, including cross-part joins. After previewing all commands, intersect that set with surviving owners, allocate disconnected-part splits, then append cleanup only for affected parts with no remaining nodes. A remove-then-add batch preserves its part/settings. Pre-existing unrelated empty/template/import parts remain untouched. Explicit cleanup earlier in a batch cannot leave stale affected IDs. Cleanup and splitting share deletion's single undo transaction; Cut uses that same path.

Detach empty part-linked leaf components. Ignore formatting-only whitespace text when identifying leaves. When a reference has meaningful children (nested geometry, unknown XML, comments or nonblank text), retain it as an ordered group by removing only `linkData`/`linkDataType`. Do not recursively collect surrounding groups. Clear known UUID-shaped cut-face links to removed owners on node/part records; absent node links inherit the owner's cut face, absent owner links use the existing default. Named presets, arbitrary non-UUID IDs, other references and unknown fields are preserved. This dependency repair can affect readonly surviving records because their referenced profile no longer exists, just as cross-part joins rewrite linked references; it does not move their nodes or change their part flags.

Qt `removeNode` rebuilds surviving groups then removes the old part/component; `removePart` delegates to recursive component removal. Native code deliberately preserves surviving identities and unknown/nested content instead of recursively deleting it. Qt can leave a removed profile link when no replacement group exists; native cleanup explicitly restores default/inherited shape, with pinned-core generation coverage. No implicit cleanup occurs on Open/Save, no assets are removed, and inherited unsupported data outside the affected owners remains preserved.

No new dependencies, C++/core pin, UI controls or CI changes are needed. Existing state publication prunes deleted part/node selection without reviving it on Undo; preview clears when no enabled geometry remains.
