# ADR 0016: Bounded native reference images and Qt canvas coordinates

Accepted 2026-10-15. Implements the reference-image import/display stage of M2, tracked in #33.

Use Apple's built-in ImageIO/CoreGraphics/UniformTypeIdentifiers at the app boundary, with no third-party dependency. A per-window actor reads and converts files, decodes existing PNG assets, and caches the current immutable CGImage. Model-only edits do not reload that cache. Reference-image bytes stay in Dust3DDocument; rendering never re-encodes existing assets. Import/removal use the existing immutable document command and undo transaction; display visibility and opacity are transient per-window values.

Read through a bounded FileHandle under the selected URL's security scope, including a cap if the file grows after metadata inspection. Limit input/output encoded bytes to 32 MiB, dimensions to 8192 per side and decoded pixel product to 16,777,216 before decoding. Inspect existing archive image byte count before materializing its payload. Allow PNG/JPEG/BMP/GIF/TIFF, use the first frame, bake image orientation into the converted PNG, and reject incomplete/unsupported/failed decoding with typed errors. Existing malformed/oversized reference assets remain preserved; a preview error does not block graph editing or saving, and removal remains available.

Qt uses scene coordinates normalized by image height (`SkeletonGraphicsWidget::scenePosToUnified`/`scenePosFromUnified`). Draw the complete canvas.png at X/Z [0, width/height], Y [0,1], with positive Y down, and fit the union of the image rectangle and visible node bounds. This deliberately corrects the prototype's former Y-up canvas projection; screen dragging follows the new projection. Adjust front/side clockwise formulas to match the visible direction and Qt's context-menu rotation (`rotateItems`, positive screen-space rotation), retaining locks and exact undo. No document coordinates are migrated or rewritten on open.

Asset-only changes can advance document revision without changing geometry. Mesh preview publication therefore relies on the existing fresh request identity/cancellation checks, rather than rejecting an otherwise current mesh solely on document revision. Import/removal skip geometry generation; Undo/Redo still regenerate as needed through the common path. Reference-image tasks use separate request identities, so replaced/closed scenes reject obsolete results.

The current native UI imports one already-composed reference image. Qt's crop/multiple-image composition and origin-editing tools remain follow-up work; no Qt GUI differential or full M2 parity is claimed. Tests cover codec/resource errors, orientation, cache behavior, controller/history independence, image/node fit and Qt-coordinate transforms. Native QA checks actual alignment, display controls, save/reopen, undo/redo and malformed-asset preservation.
